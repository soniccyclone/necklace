* How it works
:PROPERTIES:
:CUSTOM_ID: how
:END:

1. *A planning document*, researched by exercising real code paths rather than reading source and reasoning about it.
2. *A CUJ technical design document*, one vertical slice per outcome, each naming the tests that close it.
3. *A beads breakdown*, worked to completion.

The code is the source of truth. The documents are provenance.

* Requires beads
:PROPERTIES:
:CUSTOM_ID: requires
:END:

necklace checks for [[https://github.com/gastownhall/beads][beads]] and tells you what to run. It never installs anything on your behalf.
